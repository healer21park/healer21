# hiking-briefing spec

## 개요

산 이름·날짜·출발역·등산 출발지/도착지를 입력하면,
지도 위에 경로·대피소를 시각화하고 날씨·교통·마라톤 일정을 사이드패널에 브리핑하는 웹앱.

---

## 레이아웃

- **왼쪽 사이드패널**: 입력 폼 + 날씨·대피소·교통·마라톤 브리핑 카드
- **오른쪽 메인**: 지도 (전체 화면 높이)

---

## 시나리오

### S1. 랜딩 및 초기 지도

**Given** 사용자가 앱에 접속한다  
**When** 초기 로드  
**Then**
- 사이드패널에 서비스 소개 문구와 입력 폼이 표시된다
- 지도는 대한민국 전체가 보이는 줌 레벨로 표시된다
- 입력 폼 항목: 산 선택(드롭다운), 날짜, 기차 출발역, 등산 출발지(드롭다운), 등산 도착지(드롭다운)

---

### S2. 산 선택 시 지도 줌 및 추천 등산로 표시

**Given** 사용자가 산을 선택한다  
**When** 산 드롭다운에서 지리산 / 설악산 / 덕유산 / 소백산 중 하나를 선택  
**Then**
- 지도가 선택한 산 중심으로 줌인된다
- 해당 산의 추천 등산로 목록이 표시된다 (이름 + 거리 + 예상 소요 시간)
- 등산 출발지·도착지 드롭다운은 추천 등산로 선택 전까지 비어 있는 상태다

---

### S2-1. 추천 등산로 선택

**Given** 추천 등산로 목록이 표시된 상태  
**When** 사용자가 등산로 하나를 선택한다  
**Then**
- 등산 출발지가 해당 등산로의 시작 지점으로 자동 입력된다
- 등산 도착지가 해당 등산로의 종료 지점으로 자동 입력된다
- 지도에 해당 등산로의 경로와 대피소 마커가 표시된다

---

### S2-2. 출발지·도착지 역순 변경

**Given** 등산 출발지와 도착지가 입력된 상태  
**When** 역순 전환 버튼을 클릭한다  
**Then**
- 출발지와 도착지가 서로 바뀐다
- 지도의 경로 방향도 함께 반전된다

---

### S3. 등산 경로 및 대피소 표시

**Given** 등산 출발지와 도착지가 모두 선택된 상태  
**When** 두 지점이 선택된다  
**Then**
- 지도에 출발지→도착지 경로가 선으로 표시된다
- 선택한 산의 대피소 위치가 지도 위에 마커로 표시된다
- 사이드패널의 대피소 목록에서 항목을 클릭하면 지도가 해당 대피소 위치로 이동한다

---

### S4. 브리핑 조회 (정상)

**Given** 산·날짜·기차 출발역·등산 출발지·도착지가 모두 입력된 상태  
**When** "브리핑 보기" 버튼을 클릭한다  
**Then**
- 사이드패널에 4개 섹션(날씨 / 대피소 / 교통 / 마라톤)의 스켈레톤 UI가 먼저 표시된다
- 데이터가 도착하는 순서대로 섹션이 실제 데이터로 교체된다

#### S4-1. 날씨 섹션

**Given** 날씨 조회가 완료된다  
**Then** 선택한 날짜의 날씨 상태(맑음/흐림/비/눈)와 기온이 표시된다

#### S4-2. 대피소 섹션

**Given** 대피소 조회가 완료된다  
**Then**
- 선택한 산의 모든 대피소가 목록으로 표시된다
- 각 대피소마다 선택한 날짜의 잔여 수용 인원이 표시된다
- 잔여 인원이 0인 대피소도 목록에 포함되며 만실로 표시된다
- 목록 항목 클릭 시 지도가 해당 대피소 위치로 이동한다

#### S4-3. 교통 섹션

**Given** KTX·SRT 조회가 완료된다  
**Then** 입력한 기차 출발역에서 선택한 산의 가장 가까운 도착역까지의 당일 시간표가 표시된다

#### S4-4. 마라톤 섹션

**Given** 마라톤 일정 조회가 완료된다  
**Then**
- 선택한 날짜 기준 앞뒤 30일 이내 마라톤·트라이애슬론 대회 목록이 표시된다
- 각 대회의 이름·날짜·지역·접수 마감일·공식 사이트 링크가 표시된다
- 해당 기간에 대회가 없으면 "근방 대회 없음" 문구가 표시된다

---

### S4-5. 등산로 콘텐츠 섹션

**Given** 등산로 조회가 완료된다 (S2-1에서 등산로 선택)  
**Then**
- 선택한 등산로 이름으로 검색한 네이버 블로그 게시글 목록이 표시된다
  - 각 항목: 제목 + 작성일 + 블로그 링크
- 선택한 등산로 이름으로 검색한 YouTube 동영상 목록이 표시된다
  - 각 항목: 썸네일 + 제목 + 채널명 + YouTube 링크
- 콘텐츠가 없으면 "관련 콘텐츠 없음" 문구가 표시된다
- 각 항목은 외부 링크로 열린다 (새 탭)

---

### S5. 입력 유효성 검사

**Given** 산·날짜·기차 출발역 중 하나 이상이 비어 있다  
**When** "브리핑 보기" 버튼을 클릭한다  
**Then**
- 브리핑이 시작되지 않는다
- 비어 있는 필드에 오류 표시가 나타난다

---

### S6. 섹션별 조회 실패

**Given** 특정 섹션의 데이터 조회가 실패한다  
**Then**
- 해당 섹션에 오류 메시지와 재시도 버튼이 표시된다
- 나머지 섹션은 정상적으로 표시된다

---

## 불변 규칙

- 실제 예약 실행 기능은 없다 — 조회·표시만 한다
- 로그인·사용자 계정 기능은 없다
- LLM API를 사용하지 않는다
- 기차 출발역(교통용)과 등산 출발지(지도·경로용)는 별개 입력이다

---

## 제외 항목

| 항목 | 이유 |
|---|---|
| 실제 예약 실행 | 국립공원 예약 시스템의 CAPTCHA로 자동화 불가 |
| 실제 등산로 트레일 경로 | 등산로 데이터 출처 미확정 — 직선/도로 경로로 MVP 대체 |
| 자연어 입력 | MVP에서 검증할 핵심 가치 아님 |
| 모바일 PWA | 핵심 기능 검증 후 추가 |
| 즐겨찾기·알림 | 로그인 없이 구현 불가 |
